# Команды

1. git init - делает из обычной папки репазиторий, то есть поесле выполенния этой команды папка станоситься отслеживаемой.
2. git config --global user.name "Dasha" - пoдписываем коммиты
3. git config --global user.email "starostina10092005@gmail.com" - подписываем коммиты
4. gid add - добавляем файлы (конкретный или все -А)
5. git commit -m - создаем коммид и присваиваем ему имя
6. git remote add origin - связываем git с github 
7. git push -u origin main - отправляет изменения на github
